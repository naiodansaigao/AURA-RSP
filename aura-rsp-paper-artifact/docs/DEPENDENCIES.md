# Dependencies

The authoritative Python dependency declaration is `pysim-aura-integration/setup.py` with extras `smdpp`, `aura` and `experiment`. The WSL setup also installs `kyber-py==1.2.0` for Experiment 9.

Important research-prototype dependencies include:

- Osmocom pySim/osmo-smdpp source, GPL-2.0;
- Twisted/Klein and Requests for local HTTPS protocol paths;
- `cryptography` and PyCryptodome for certificates, AEAD and elliptic-curve operations;
- `py-ecc==8.0.0` for the BBS+ research prototype;
- `kyber-py==1.2.0` for the explicit Hybrid/ML-KEM experiment;
- Pillow for publication plots generated by the experiment scripts.

`kyber-py` is used for reproducible research measurements and is not claimed to be a hardened constant-time production implementation.
