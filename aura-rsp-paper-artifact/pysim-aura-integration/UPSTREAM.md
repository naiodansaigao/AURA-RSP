# Upstream provenance

This integration tree was copied from the pySim/osmo-smdpp baseline pinned at:

- upstream project: Osmocom pySim
- baseline commit: `25e43e1540144be9026a2733bc3a4271b8fa7d25`
- baseline component: `osmo-smdpp.py` plus `pySim.esim`

The integration was intentionally developed in this separate tree.  The
existing `rsp-baseline`, standalone `aura-rsp`, and the 13 experiment
directories are not runtime dependencies of this tree and are not modified by
its scripts.
